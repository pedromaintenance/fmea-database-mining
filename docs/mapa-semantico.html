Mapa semântico dos datasets

Explore esquemas, versões, natureza declarada, domínios prováveis e vínculos bibliográficos. Metadados gerados a partir dos arquivos públicos da biblioteca.

O mapa é uma ferramenta de descoberta. A categorização por tema usa nomes de arquivos, não revisão técnica humana. Ausência de vínculo explícito não demonstra que a ficha é órfã, e uma referência bibliográfica não comprova sua aplicabilidade OEM. Os resultados não autorizam intervenções.

Fonte do mapa: repositório público versionado. Execute npm run knowledge:atlas:build para gerar uma cópia atualizada ao clonar. Perfis/assuntos indicativos, sem dados privados ou valores OEM de aceitação.
